# Task Management Web Application

## 📌 Project Description
This is a simple Task Management Web Application that allows users to add, view, update, and delete tasks. It helps users organize their daily work efficiently.

## 🚀 Technologies Used
- JavaScript (ES6)
- Node.js
- Express.js
- MongoDB
- HTML
- CSS
- Git & GitHub

## ⚙️ Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Search tasks
