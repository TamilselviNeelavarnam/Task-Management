# 🗂 Task Management Web Application

A simple **Task Management Web Application** built using **JavaScript (ES6), Node.js, Express.js, and MongoDB**.  
This application allows users to add, view, update, and delete tasks efficiently.

---

## 🚀 Features

- Add new tasks
- View task list dynamically
- Mark tasks as **Completed** or **Pending**
- Delete tasks
- Task statistics (Total / Pending / Completed)
- Responsive UI with modern styling
